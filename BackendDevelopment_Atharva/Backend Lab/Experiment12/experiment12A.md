# Experiment 12A – Node.js, Express.js and EJS Templating

## Overview

This experiment focuses on server-side JavaScript development using Node.js and Express.js. It covers creating web servers, handling HTTP requests, working with URL parameters and POST data, and rendering dynamic webpages using EJS.

## Technologies Used

- Node.js
- Express.js
- EJS
- NPM
- Nodemon

## Key Concepts Covered

1. **Node.js:** Running JavaScript on the server side.
2. **NPM:** Managing project dependencies and scripts.
3. **Express.js:** Creating web servers and REST API routes.
4. **HTTP Responses:** Using `res.send()`, `res.json()`, `res.render()` and `res.status()`.
5. **URL Parameters:** Accessing route parameters using `req.params`.
6. **Query Parameters:** Handling query strings using `req.query`.
7. **POST Requests:** Processing JSON and form data using Express middleware.
8. **EJS Templating:** Rendering dynamic HTML using templates and JavaScript.
9. **Nodemon:** Automatically restarting the server when files change.

## Practical Tasks

- Creating a basic Node.js and Express server.
- Building a calculator API.
- Handling user registration and login requests.
- Creating student management routes.
- Rendering dynamic pages using EJS.
- Handling student registration forms.

## Learning Outcomes

- Develop backend applications using Node.js and Express.js.
- Create and manage API routes.
- Handle GET and POST requests.
- Work with URL and query parameters.
- Generate dynamic webpages using EJS.
- Use Nodemon for development.

## Conclusion

This experiment introduces essential backend development concepts using Node.js and Express.js, including API development, request handling, dynamic templating and server management.
