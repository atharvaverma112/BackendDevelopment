# Experiment 13A – User Registration and Login

## Overview

This experiment focuses on developing a user authentication system using Node.js, Express.js, MongoDB and Mongoose.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose

## Key Features

1. MongoDB database connection using Mongoose.
2. User schema and model creation.
3. User registration.
4. User login.
5. Viewing all registered users.
6. Express routing for handling user requests.

## Concepts Covered

- Backend server development.
- MongoDB connectivity.
- Mongoose schemas and models.
- Express.js routes.
- User authentication fundamentals.

## Learning Outcomes

- Connect Node.js applications to MongoDB.
- Create and manage user records.
- Implement registration and login functionality.
- Understand backend routing and database operations.

## Conclusion

This experiment demonstrates the development of a basic user registration and login system using Node.js, Express.js and MongoDB.
