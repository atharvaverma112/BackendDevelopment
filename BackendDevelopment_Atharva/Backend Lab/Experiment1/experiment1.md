# Experiment 1 – Skincare Hub

## Overview

Developed a skincare information website called **Skincare Hub** using HTML, CSS and JavaScript. The website provides skincare information, ingredient comparisons, routine suggestions and an interactive skin profile form.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Key Features

1. **Navigation:** Sections for Home, About, Routines, Ingredients, Skin Profile and Media.
2. **Skincare Information:** Displays skincare routines, skin types and active ingredients.
3. **Ingredient Comparison:** Uses HTML tables to compare skincare ingredients.
4. **Skin Profile Form:** Collects personal information, skin type, sensitivity and skincare concerns.
5. **Form Validation:** Provides live validation with green and red indicators.
6. **Multimedia:** Includes images, audio and video elements.
7. **Interactive Elements:** Uses expandable details, ingredient search suggestions and a warning dialog.
8. **Responsive Design:** Uses CSS media queries to support different screen sizes.

## Concepts Covered

- HTML semantic elements and forms.
- CSS selectors, layouts and responsive design.
- HTML tables, lists and multimedia elements.
- JavaScript DOM manipulation and event handling.
- Form validation and interactive elements.
- HTML5 dialog, progress and meter elements.

## Learning Outcomes

- Create structured webpages using HTML.
- Apply styling and responsive layouts using CSS.
- Add interactivity using JavaScript.
- Implement client-side form validation.
- Work with multimedia and interactive HTML elements.

## Conclusion

This experiment demonstrates the practical application of HTML, CSS and JavaScript by developing a responsive and interactive skincare information website.
