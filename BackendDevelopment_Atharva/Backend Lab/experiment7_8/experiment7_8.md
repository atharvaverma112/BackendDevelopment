# Experiment 7 & 8 – JavaScript ES6, DOM Manipulation and Events

## Overview

This experiment demonstrates JavaScript ES6 features, DOM manipulation and event handling through a simple interactive webpage.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

- `index.html` – Defines the webpage structure.
- `style.css` – Handles webpage styling.
- `script.js` – Implements JavaScript functionality.

## Key Concepts Covered

1. **ES6 Variables:** Using `let` and `const`.
2. **Template Literals:** Displaying dynamic messages using `${}`.
3. **Arrow Functions:** Creating functions using arrow syntax.
4. **DOM Manipulation:** Accessing and modifying HTML elements using `getElementById()`.
5. **Event Handling:** Using `addEventListener()` to handle button clicks.
6. **Dynamic Styling:** Changing text color and webpage background using JavaScript.

## Practical Features

- Displays a personalized welcome message.
- Changes the heading when the Change Message button is clicked.
- Changes the webpage background when the Change Background button is clicked.

## Learning Outcomes

- Understand JavaScript ES6 syntax.
- Manipulate HTML elements using the DOM.
- Handle user interactions through events.
- Dynamically modify webpage content and styling.

## Conclusion

This experiment provides practical knowledge of modern JavaScript features and demonstrates how JavaScript can make webpages interactive through DOM manipulation and event handling.
