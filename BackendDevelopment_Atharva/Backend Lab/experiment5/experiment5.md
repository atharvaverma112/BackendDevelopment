# Experiment 5 – JavaScript Arrays, Objects and Functions

## Overview

This experiment focuses on demonstrating fundamental JavaScript concepts, including arrays, objects and functions, using Node.js.

## Technologies Used

- JavaScript
- Node.js

## Project Structure

- `experiment5.js` – Contains the JavaScript practical programs.

## Concepts Covered

### 1. Arrays
- Creating and accessing arrays.
- Accessing elements using indexes.
- Using `push()` and `pop()` methods.
- Finding array length using `length`.

### 2. Objects and Functions
- Introduction to JavaScript objects and functions as part of the experiment topic.

## Execution

Run the program using:

```bash
node experiment5.js
```

## Learning Outcomes

- Understand JavaScript arrays and their operations.
- Learn basic object and function concepts.
- Execute JavaScript programs using Node.js.

## Conclusion

This experiment introduces fundamental JavaScript programming concepts and demonstrates basic array operations using Node.js.
