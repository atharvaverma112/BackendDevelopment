# Assignment 1 – My Notes App

## Overview

Developed a simple Notes App using HTML, CSS and JavaScript. The application allows users to create, view, edit and delete notes, with data stored in the browser's localStorage.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Project Structure

- `index.html` – Defines the application structure.
- `style.css` – Handles styling and layout.
- `script.js` – Implements note management functionality.

## Key Features

1. **Add Notes:** Create new notes using the input field.
2. **View Notes:** Display all saved notes.
3. **Edit Notes:** Modify existing notes.
4. **Delete Notes:** Remove notes from the application.
5. **Local Storage:** Save notes in the browser using localStorage.
6. **Timestamps:** Store creation and last-updated dates for each note.
7. **Input Validation:** Prevent adding empty notes.

## Concepts Covered

- DOM manipulation.
- JavaScript functions and event handling.
- Arrays and objects.
- JSON parsing and stringification.
- Browser localStorage.
- Date and time handling.
- Dynamic HTML element creation.

## Learning Outcomes

- Build interactive frontend applications.
- Perform CRUD operations using JavaScript.
- Store and retrieve data using localStorage.
- Dynamically update webpage content through the DOM.

## Conclusion

This assignment demonstrates a browser-based Notes App with complete note management functionality and persistent data storage using JavaScript localStorage.
