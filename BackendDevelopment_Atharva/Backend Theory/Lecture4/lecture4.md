# Lecture 4 – Student API and Data Fetching

## Overview

This lecture focuses on developing a Student API using backend technologies and understanding how frontend applications can fetch and display student data.

The practical work includes Node.js, Express.js, Python, and HTML.

## Project Structure

The Lecture 4 folder contains the following files:

| File/Folder | Description |
|---|---|
| `server.js` | Backend server implementation using Node.js and Express.js |
| `app.py` | Python backend application |
| `fetch-students.html` | HTML page for fetching and displaying student data |
| `package.json` | Contains project information and Node.js dependencies |
| `package-lock.json` | Records the installed dependency versions |
| `node_modules/` | Contains installed Node.js packages |
| `screenshots/` | Stores screenshots of the practical work |
| `lecture4.md` | Lecture documentation |

## Technologies Used

- **Node.js:** JavaScript runtime for backend development.
- **Express.js:** Framework for creating backend servers and API routes.
- **Python:** Programming language used for backend development.
- **HTML:** Used to create the frontend page.
- **JavaScript Fetch API:** Used to request data from the backend.
- **VS Code:** Code editor used for development.

## Key Concepts

### 1. Backend Server Development

Creating and running a backend server using Node.js and Express.js.

### 2. Python Backend

Using Python to implement a backend application through `app.py`.

### 3. Student API

Working with student-related data through a backend API.

### 4. Fetching Student Data

Using `fetch-students.html` to understand how a frontend page can request student data from a backend server.

### 5. Frontend and Backend Communication

Understanding how a frontend application communicates with a backend through HTTP requests and receives data from API endpoints.

## Learning Outcomes

After completing this practical, students should be able to:

1. Create and run a backend application using Node.js and Express.js.
2. Understand the structure of a Python backend application.
3. Work with student-related API data.
4. Understand how frontend applications fetch data from backend APIs.
5. Understand basic communication between frontend and backend applications.

## Conclusion

Lecture 4 provides practical experience in backend development and frontend-backend communication. It introduces the use of APIs for handling student data and demonstrates how frontend applications can retrieve information from backend services.
