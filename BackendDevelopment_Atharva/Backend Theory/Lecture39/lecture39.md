# Lecture 39 – Docker Student API

## Overview

This lecture focuses on containerized backend applications. The project contains two implementations of a Student API using Express.js and FastAPI.

## Project Structure

- `docker-student-api/` – Main project directory.
- `express-app/` – Express.js backend application.
- `fastapi-app/` – FastAPI backend application.

## Technologies Used

- Docker
- Node.js
- Express.js
- Python
- FastAPI

## Key Concepts

- Backend application containerization.
- Docker-based application deployment.
- Express.js backend application.
- FastAPI backend application.
- Working with different backend frameworks.

## Learning Outcomes

- Understand Docker-based backend projects.
- Identify the structure of Express.js and FastAPI applications.
- Understand the concept of containerizing backend services.
- Compare two backend implementations of a Student API.

## Conclusion

Lecture 39 introduces Docker-based backend application development using Express.js and FastAPI, demonstrating two different frameworks within a common Student API project.
