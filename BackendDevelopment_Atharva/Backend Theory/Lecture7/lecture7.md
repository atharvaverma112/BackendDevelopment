# Lecture 7 – Frontend Development

## Overview

This lecture contains practical work related to frontend web development using HTML, CSS, and JavaScript. The project is structured into separate files for webpage content, styling, and functionality.

## Project Structure

| File/Folder | Description |
|---|---|
| `index.html` | Main HTML file that defines the webpage structure |
| `style.css` | CSS file used for styling and designing the webpage |
| `script.js` | JavaScript file used to add functionality and interactivity |
| `screenshots/` | Stores screenshots of the practical work |
| `lecture7.md` | Documentation for the lecture |

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## Key Concepts

### 1. HTML

Used to create the structure and content of the webpage.

### 2. CSS

Used to style webpage elements, including colors, layouts, spacing, and fonts.

### 3. JavaScript

Used to implement functionality and interactive behaviour on the webpage.

### 4. Linking HTML, CSS, and JavaScript

Understanding how separate HTML, CSS, and JavaScript files work together to create a functional webpage.

## Learning Outcomes

After completing this practical, students should be able to:

1. Create a webpage using HTML.
2. Apply styling using CSS.
3. Add interactive functionality using JavaScript.
4. Connect external CSS and JavaScript files to an HTML document.
5. Organize a basic frontend web development project.

## Conclusion

Lecture 7 introduces the fundamentals of frontend development and demonstrates how HTML, CSS, and JavaScript work together to build interactive webpages.
