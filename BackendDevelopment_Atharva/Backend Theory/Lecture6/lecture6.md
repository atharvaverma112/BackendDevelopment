# Lecture 6 – Node.js Backend Development

## Overview

This lecture contains practical work related to backend development using Node.js. The project uses JavaScript to implement a backend server.

## Project Structure

| File/Folder | Description |
|---|---|
| `server.js` | Main backend server file |
| `package.json` | Contains project details and dependencies |
| `package-lock.json` | Records the installed dependency versions |
| `node_modules/` | Contains installed Node.js packages |
| `screenshots/` | Stores screenshots of the practical work |

## Technologies Used

- Node.js
- JavaScript
- npm (Node Package Manager)
- Visual Studio Code

## Key Concepts

### 1. Node.js

Using Node.js to execute JavaScript outside the browser and develop backend applications.

### 2. Backend Server

Creating and running a backend server using the `server.js` file.

### 3. npm and Dependencies

Understanding how npm manages project dependencies through `package.json` and `package-lock.json`.

## Learning Outcomes

After completing this practical, students should be able to:

1. Set up a Node.js backend project.
2. Understand the structure of a Node.js application.
3. Run a backend server using JavaScript.
4. Manage project dependencies using npm.
5. Organize project files and practical screenshots.

## Conclusion

Lecture 6 provides practical exposure to Node.js backend development, including server execution and dependency management using npm.
